A tiny Node program (stdlib only) that writes a one-sentence absurd micro-startup pitch to `entry.txt`. The pitch: NapkinAI turns a photo of a napkin sketch into a 40-slide deck, a valuation, and a co-founder who only says "synergy".

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the pitch to `out/entry.txt`, byte-identical on every run.
